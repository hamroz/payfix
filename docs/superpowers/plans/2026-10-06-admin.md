# Platform admin and tester feedback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An allowlisted operator area at `/admin` (stats, users, companies, feedback, moderation, audit, CSV exports) plus a public `/feedback` survey, without exposing companies' internal data.

**Architecture:** Services under `src/lib/server/admin/` and `src/lib/server/feedback.ts` take `{ db }` and are tested on PGlite. A separate `admin` session kind (cookie `pf_a`) guards `/admin` and `/api/admin/*`; admin codes bypass the demo inbox. Suspension is enforced at the existing chokepoints (`sendCode`/`verifyCode`, `currentUser`, `requireWorkspace`, `findLink`, `createPaymentRequest`, the faucet).

**Tech Stack:** Next.js 16 App Router, React 19, Drizzle + PGlite/Postgres, zod, vitest, Tailwind 4 tokens, lucide icons.

**Spec:** `docs/superpowers/specs/2026-10-06-admin-design.md`

## Global Constraints

- Read `node_modules/next/dist/docs/` before using a Next API you haven't used in this repo. `params`/`cookies()` are async; `refresh()` from `next/cache` after mutations.
- No hard-coded user-visible text. English in `src/lib/i18n/messages/en/<ns>.ts`; every key mirrored, translated naturally, in `ru de pl fi es zh hi`. User-facing errors are `InputError(key)`/`UserError`.
- Colors only from theme tokens (`veil/…`, `indigo`, `violet`, `mint`, `cyan`, `periwinkle`, `fg-*`, `ink-*`); light and dark. Amounts `tabular`, `formatUsd`.
- Money is `bigint`. Never per-company amounts in admin views or exports.
- Admin output (pages + CSV) never includes: customer names/emails, invoice numbers/titles, wallet addresses/secrets, payment references, link tokens, sign-in codes.
- Every admin mutation runs in one transaction with its `admin_audit` row; reasons required (1–500 chars, trimmed).
- `ADMIN_EMAILS` is comma-separated, trimmed, lowercased. Admin session TTL 12 h.
- Commits: plain messages, no trailers. Run `npm test` after changes to `src/lib/{domain,server,solana}`.

## Review Focus

1. Admin email typed into the business login on the demo → the demo inbox must still never show an admin code (test in Task 2: admin outbox row status is `pending`/`sent`, and the inbox route filters `status = 'demo'`).
2. Admin removed from `ADMIN_EMAILS` while signed in → next request 404s (test in Task 2).
3. A member of two companies, one suspended → can still switch to and use the other (test in Task 9 via `requireWorkspace` redirect only when the *chosen* company is suspended, and switcher listing both).
4. Feedback with surrogate-pair/emoji or 2,001-char answers, negative minutes, NPS 11 → rejected or trimmed per schema, never a 500 (test in Task 4).
5. CSV cells starting with `=`, `+`, `-`, `@` (formula injection from a company name or survey answer) → prefixed with `'` (test in Task 5).
